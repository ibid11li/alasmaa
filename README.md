Alasmaa | Arabic Names Explorer
A web application for exploring Arabic names and their meanings, built using Python, FastAPI, and SQL.

The project provides a simple way to discover Arabic names through a searchable database containing over 1,000 names.
Features
- Search names by gender
- Filter names by the number of letters
- Search for names containing a specific letter
- View Arabic names and their meanings
- Combine multiple optional filters
Technologies
- Python – Backend development
- FastAPI – REST API
- MySQL – Database management
- HTML, CSS & JavaScript – Web interface
How It Works
The application sends user-selected filters to a FastAPI endpoint. The backend builds parameterized SQL queries to retrieve matching names from the database and returns the results to the interface.
